# Actividad 7 - Detalle dinámico de películas

Código base para practicar parámetros de URL, `URLSearchParams`, `find()` y modificación del DOM mediante una cartelera de cine.

## Archivos que deben completarse

- `js/cartelera.js`
- `js/detalle.js`

Buscá los comentarios identificados con `TODO`. El archivo `js/peliculas.js` y los archivos HTML ya se encuentran preparados. Las tarjetas muestran afiches, días, horarios, idioma, formato y clasificación. La página de detalle está preparada para mostrar además duración, director, reparto, país y sinopsis.

## Cómo comenzar

1. Abrí `index.html` en el navegador.
2. Revisá el array almacenado en `js/peliculas.js`.
3. Completá los `TODO` en el orden indicado.
4. Probá las cuatro películas.
5. Probá también un identificador inexistente, como `detalle.html?id=m99`.

Podés abrir los archivos directamente o utilizar Live Server desde Visual Studio Code.
